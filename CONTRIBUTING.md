# Contributing to ThinkingBox Training

We welcome contributions and suggestions.

## Contributor License Agreement

All contributions are subject to the Microsoft Contributor License Agreement
(CLA), which declares that you have the right to, and actually do, grant us
the rights to use your contribution. For details, visit
<https://cla.opensource.microsoft.com>.

When you submit a pull request, a CLA bot will automatically determine whether
you need to sign an agreement or are already covered by one, and decorate the
pull request appropriately. Follow the instructions provided by the bot. You
only need to complete the CLA once across repositories using the Microsoft
CLA.

## How to contribute

1. Open an issue describing the proposed change when the scope or expected
   behavior needs discussion.
2. Create a focused branch and keep unrelated changes out of the pull request.
3. Add or update tests and documentation for behavior changes.
4. Run the repository's relevant formatting, validation, and test commands.
5. Submit a pull request with a clear description of the change and its
   validation.

Do not include training data, private task selectors, credentials, endpoint
configuration, model weights, generated trajectories, or other confidential
artifacts in a contribution.

## Code of Conduct

This project has adopted the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).

## Security

Do not report security vulnerabilities through public GitHub issues. Report
them to the Microsoft Security Response Center using the
[MSRC reporting portal](https://msrc.microsoft.com/create-report).
